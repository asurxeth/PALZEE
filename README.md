## The Social Platform Reimagined

PALZEE is a **next-generation Android-first social platform** built around **privacy**, **meaningful relationships**, and **user control**.

Instead of chasing engagement through endless feeds and attention-driven algorithms, PALZEE focuses on helping close friends capture, relive, and share authentic moments in a way that feels effortless.

Built natively with **Kotlin**, **Jetpack Compose**, **CameraX**, **Media3**, and **Supabase**, every interaction is engineered for speed, reliability, and a seamless user experience.

# Why PALZEE?

Today's social platforms were designed to maximize **attention**.

Feeds never end.

Algorithms decide what people see.

Success is measured by likes, followers and screen time.

Over time, sharing moments became less about people—and more about performance.

PALZEE started with a simple question:

> **What if social media was designed for relationships instead of engagement?**

Rather than competing for attention, PALZEE is built to quietly help people stay connected with the people who matter most.

---

# Our Vision

> **Build a social platform people trust—not one they need to escape from.**

We believe technology should strengthen real relationships instead of replacing them.

The best social experiences don't encourage people to spend more time online.

They make the time they do spend together more meaningful.

PALZEE is our attempt to rethink social networking from first principles.

---

# Our Philosophy

We believe every product decision should answer one simple question:

> **Does this help people build better relationships?**

If the answer is no,

it doesn't belong in PALZEE.

This philosophy influences everything—from the interface and media pipeline to privacy controls, backend architecture and feature roadmap.

# Engineering

PALZEE is designed as a **production-first Android application** where architecture, performance and long-term maintainability are treated as product features—not afterthoughts.

Every major component is chosen to solve a specific engineering problem while keeping the experience fast, reliable and scalable.

---

## Architecture

<div align="center">

<img src="./assets/architecture.svg" width="100%" alt="PALZEE Architecture"/>

</div>

PALZEE follows a layered architecture with clear separation between presentation, business logic, local storage and cloud services.

```
Compose UI
      │
      ▼
 ViewModels
      │
      ▼
Repositories
      │
 ┌────┴────┐
 │         │
 ▼         ▼
Local    Supabase
Storage   Backend
 │         │
 └────┬────┘
      ▼
 PostgreSQL
```

This keeps the application modular, predictable and easy to extend as new features are introduced.

---

# Engineering Principles

### ⚡ Native Performance

Every interaction should feel immediate.

From camera launch to media playback, PALZEE is optimized to minimize perceived latency and deliver a consistently smooth experience.

---

### 📦 Local-first Media

Media is prepared locally before cloud synchronization whenever possible.

This allows users to interact with their content instantly while uploads continue in the background.

---

### 🔄 Realtime Synchronization

Instead of relying on frequent polling, PALZEE uses realtime subscriptions to synchronize conversations, group activity and shared content efficiently.

---

### 🔒 Privacy by Design

Privacy isn't implemented as an optional feature.

It influences the architecture itself—from data ownership to permanent deletion and controlled sharing.

# Getting Started

Get PALZEE running locally in just a few minutes.

---

## Requirements

- Android Studio (Latest Stable)
- JDK 17+
- Android SDK 36
- Gradle 8+
- Android Device / Emulator (Android 10+)

---

## Clone the Repository

```bash
git clone https://github.com/asurxeth/PALZEE.git

cd PALZEE
```

---

## Configure Environment

Create a `.env` file in the project root.

```env
SUPABASE_URL=YOUR_SUPABASE_URL
SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
GOOGLE_WEB_CLIENT_ID=YOUR_GOOGLE_WEB_CLIENT_ID
```

Add your Firebase configuration.

```
app/
└── google-services.json
```

> Additional setup instructions can be found inside the `/docs` directory.

---

## Build

Debug

```bash
./gradlew assembleDebug
```

Release

```bash
./gradlew assembleRelease
```

Install

```bash
./gradlew installDebug
```
